## 🧭 ひとことで言うと

**HTML** でアプリの **入れ物（空の箱）** を用意し、**CSS** で色・形・配置を決めている部分です。中身（タスクの一覧など）は後から JavaScript が箱に流し込みます。

## 🗺️ 全体の流れ

1. `<head>`：文字コード・スマホ対応・タイトル・フォント・CSS を読み込む
2. `<body>`：4 つの箱（ヘッダー・メイン・下のタブ・モーダル）を置く。**ほとんど空っぽ**
3. `<script type="module">`：JavaScript が動き出し、空の箱に HTML を入れていく

## 🔍 ブロックごとの解説

### `<head>`：ページの設定

| 行 | 意味 |
|---|---|
| `<meta charset="utf-8">` | 日本語が文字化けしないための文字コード指定 |
| `<meta name="viewport" ...>` | スマホで見たときに、画面の幅に合わせて表示する |
| `<link ... fonts.googleapis.com ...>` | Google Fonts から「Zen Kaku Gothic New」という日本語フォントを読み込む |
| `<style> … </style>` | CSS（見た目のルール）をこのファイルの中に直接書いている |

### `<body>`：4 つの空の箱

```html
<main id="main"></main>
<nav><div class="in" id="nav"></div></nav>
<div id="modal"></div>
```

`id="main"` などの **名札** が付いた空の箱です。JavaScript は `document.getElementById("main")` でこの箱を探し、中身を入れます（JavaScript コースの「DOM とイベント」）。

| 箱 | 何が入る？ |
|---|---|
| `header` の `#title` / `#meBtn` | アプリのタイトルと「👤 自分の名前」ボタン |
| `#main` | 今のタブの画面（ホーム、タスク一覧など） |
| `#nav` | 画面下の 6 つのタブ |
| `#modal` | 「あなたは誰？」や設定などの、上に重なる小窓 |

### CSS 変数：色をまとめて管理

```css
:root{ --bg:#f6f3ee; --accent:#e2553f; ... }
body{ background:var(--bg); }
```

`--bg` のように `--` で始まる名前は **CSS 変数**（色などに付けた名前）です。`var(--bg)` で使います。
色を 1 か所にまとめておくと、**変数の値を変えるだけでアプリ全体の色が変わる** ので便利です。

### ダークモード対応

```css
@media (prefers-color-scheme: dark){
  :root{ --bg:#171614; --card:#22201d; ... }
}
```

「端末がダークモードなら、変数の値をこちらにする」という意味です。CSS 変数で作っているので、**変数を入れ替えるだけで** 画面全体が暗い配色になります。

### タスクの状態ごとの色

```css
.s-todo{ ... }  .s-doing{ ... }  .s-done{ ... }
```

JavaScript がタスクのボタンに `class="chip s-doing"` のようにクラスを付けると、その状態の色になります。**状態の名前と CSS のクラス名をそろえる** よくある工夫です。

### 画面に固定された部品

- `nav{position:fixed; bottom:0}`：タブを **画面の下に固定**。スクロールしても動かない
- `body{padding-bottom:84px}`：固定したタブの裏に最後の項目が隠れないよう、下に余白を空ける
- `env(safe-area-inset-bottom)`：iPhone の画面下のバー（ホームバー）にかからないようにする
- `.modal{position:fixed; inset:0; background:rgba(0,0,0,.45)}`：画面全体を半透明の黒で覆い、真ん中に小窓を出す

## 🐍 Python と比べると

| HTML/CSS | Python で言うと |
|---|---|
| `id="main"` の空の箱 | 後から値を入れる変数 `main = ""` |
| CSS 変数 `--accent` | 定数 `ACCENT = "#e2553f"` を 1 か所に定義して使い回す |
| `@media (prefers-color-scheme: dark)` | `if dark_mode: ACCENT = "#ff7a63"` |

## 🔑 キーワード

- **HTML**：ページの骨組み（何がどこにあるか）を書く言語
- **CSS**：見た目（色・大きさ・配置）を書く言語
- **id / class**：要素に付ける名札。id は 1 つだけ、class は何個にも付けられる
- **CSS 変数**：`--名前` で値に名前を付け、`var(--名前)` で使う仕組み
- **メディアクエリ（@media）**：画面の条件（ダークモード・画面幅など）によって CSS を切り替える仕組み
- **position: fixed**：画面の決まった位置に固定する指定

## ⚠️ AI のコードとしてのチェックポイント

- ✅ 色を CSS 変数にまとめていて、ダークモードにも対応している
- ✅ スマホ（iPhone のホームバー）まで考えた配置
- ⚠️ CSS を 1 行に詰めて書いているので読みにくい。ブラウザの開発者ツール（F12）で要素を選ぶと、どの CSS が効いているか見やすく表示される
- ⚠️ フォントを Google Fonts から読み込むので、オフラインでは別のフォントで表示される（動作には影響なし）

## 🗣️ 30 秒で人に説明するなら

「HTML の部分はほとんど空の箱で、ヘッダー・メイン・下のタブ・モーダルの 4 つに id を付けて置いているだけです。中身は JavaScript が後から入れます。
CSS は色を CSS 変数にまとめていて、ダークモードのときは変数の値を入れ替えるだけで配色が変わるようになっています。タブは画面の下に固定されています。」
