## このレッスンのゴール

- Claude Code の主な使い方を挙げられる
- 「自分のパソコンで動く Claude」と「クラウドで動く Claude」の違いを説明できる
- クラウドの Claude で作業したものを残すには push が必要だと分かる

## 主な使い方

| 使い方 | どこで操作する？ | 作業場所 |
|---|---|---|
| **ターミナル（CLI）** | ターミナルで `claude` と打つ | 自分のパソコンの、今いるフォルダ |
| **デスクトップアプリ** | Mac / Windows のアプリ | 自分のパソコンの、選んだフォルダ |
| **エディタ拡張** | VS Code・JetBrains などの中 | エディタで開いているフォルダ |
| **Web（claude.ai/code）／スマホ** | ブラウザ・Claude アプリ | **クラウド上に用意された作業場所** |

名前や画面は更新で変わることがありますが、**「どこで動いているか」で 2 種類に分けられる** ことを押さえておけば迷いません。

## ① 自分のパソコンで動く Claude

```text
あなたのパソコン
 ├─ Claude（ターミナル／アプリ）
 └─ 作業フォルダ（onlineshop など）← 直接読み書きする
```

- あなたのパソコンのファイル・インストール済みのツール・ログイン情報（gh など）を使える
- 変更はすぐにあなたのフォルダに入る（GitHub に送るのは push したとき）
- パソコンを閉じると止まる

## ② クラウドで動く Claude

```text
クラウド（インターネットの向こう）
 ├─ Claude
 └─ 使い捨ての作業場所 ← 会話を始めるときに、GitHub からリポジトリを clone してくる
       │ push
       ▼
     GitHub ── pull ──▶ あなたのパソコン
```

- 会話を始めると、クラウドに **使い捨ての作業場所** が作られ、選んだリポジトリが GitHub から clone される
- あなたのパソコンの電源が切れていても作業が進む。スマホから頼める
- **作業場所は、しばらく使わないと片付けられる**。残したいものは **コミットして push** しておかないと消える
- あなたのパソコンのファイルは（つなぐ設定をしない限り）見えない

**このサイト（Readable）は、このクラウドの Claude で作られています**。だから毎回「GitHub に push → あなたのパソコンで pull」という流れになっていたのです。

## どちらを使う？

| こんなとき | 向いている方 |
|---|---|
| 自分のパソコンにしか無いファイル・アプリ・ログインを使う | ① 自分のパソコン |
| 動かした画面を自分の目でそのまま確かめたい | ① 自分のパソコン |
| 外出先から頼みたい・時間のかかる作業を任せておきたい | ② クラウド |
| パソコンの環境を汚したくない | ② クラウド |

## 権限：Claude は勝手に何でもするわけではない

どちらの場合も、Claude は **影響の大きい操作の前に確認を求めます**。

- ファイルの削除・大きな書き換え
- GitHub への push、PR の作成、Issue の作成
- 外部へのアクセス

「なぜいちいち聞くの？」と思うかもしれませんが、**取り消しにくい操作や、他の人に見える操作** を、あなたの知らないうちにしないための仕組みです。このサイトの開発中にも、「main を自動で書き換える仕組み」を入れる前に確認が入りました（レッスン 12）。
よく使う安全な操作は、設定で「毎回聞かなくていい」にすることもできます。

```quiz
? クラウドの Claude で作ったファイルを残すために必要なことは？
- 何もしなくてよい
+ コミットして GitHub に push しておく
- スマホに保存する
> クラウドの作業場所は使い捨て。GitHub に送ったものだけが残ります。

? 自分のパソコンにしか無い Excel ファイルを読んで作業してほしい。向いているのは？
+ 自分のパソコンで動く Claude（アプリ・ターミナル）
- クラウドの Claude
> クラウドの Claude からは、基本的にあなたのパソコンのファイルは見えません。

? Claude が push の前に確認を求めてくる理由は？
- Claude が push のやり方を知らないから
+ 他の人にも見える・取り消しにくい操作を、利用者が知らないうちにしないため
- GitHub の料金がかかるから
> 影響の大きい操作は、あなたの了承を取ってから行う仕組みです。
```
