## このレッスンのゴール

- CPU・メモリ・ストレージの役割を、たとえを使って説明できる
- 「プログラムを実行する」とき、この 3 つの間で何が起きているか分かる
- AI のコードで、メモリを使いすぎる書き方に気づける

## 3 つの部品は「作業する人・机・本棚」

| 部品 | たとえ | 役割 | 電源を切ると |
|---|---|---|---|
| **CPU** | 作業する人 | 計算・比較・命令の実行 | — |
| **メモリ（RAM）** | 作業机 | 今使っているデータとプログラムを置く場所。**速いが狭い** | **消える** |
| **ストレージ**（SSD・HDD） | 本棚 | ファイルをしまっておく場所。**広いが遅い** | 残る |

パソコンの「メモリ 16GB・SSD 512GB」は、「机の広さが 16GB、本棚の広さが 512GB」という意味です。

## プログラムを実行すると何が起きるか

```text
① ダブルクリック（または python main.py）
② ストレージ（本棚）から、プログラムとデータをメモリ（机）に運ぶ
③ CPU（人）が、机の上の命令を 1 つずつ読んで実行する
④ 結果をファイルに保存するときは、またストレージ（本棚）に戻す
```

Python の変数（`x = 10`）は、**メモリの上に置かれた値に名前を付けたもの** です。だからプログラムを終了すると変数の中身は消え、残したいものはファイルやデータベース（ストレージ）に保存します。

## どれくらい速さが違うのか

正確な数字は機械によって違いますが、だいたいの感覚はこうです。

| どこから読む | 1 回にかかる時間の目安 | 人間の感覚に直すと |
|---|---|---|
| CPU の中（キャッシュ） | 1 ナノ秒前後 | 1 秒 |
| メモリ | 100 ナノ秒前後 | 1〜2 分 |
| SSD | 数十〜100 マイクロ秒前後 | 1 日 |
| インターネットの向こうのサーバー | 数十〜数百ミリ秒 | 数年 |

（1 ミリ秒 = 1000 マイクロ秒 = 100 万ナノ秒）

ここから分かる大事なこと：**「ファイルを読む」「ネットワークにアクセスする」は、計算に比べてものすごく遅い**。
バックエンドコースのレッスン 14（N+1 問題）で、データベースへの問い合わせを 1 回にまとめると速くなったのは、この差のためです。

## 机が狭いと何が起きるか

メモリが足りなくなると、OS（Windows や macOS）は机の上のものを一時的に本棚へ逃がして、なんとか続けようとします（スワップ）。本棚は遅いので、**パソコン全体が急に重くなります**。それでも足りないと、プログラムが止まります。

```python
import sys
print(sys.getsizeof(list(range(1_000_000))))   # 8000056（約 8MB。中身の数値はこれとは別に必要）
```

Python のリストは、100 万個の数値を入れると、**入れ物だけで約 8MB** 使います（実際に実行して確認）。何千万件にもなると、机からあふれます。

## AI のコードではこう出てくる

大きなファイルを扱うコードは、**一度に全部を机に広げているか** を見ます。

```python
# ⚠️ ファイル全体を一度にメモリに読み込む
with open("huge.log", encoding="utf-8") as f:
    lines = f.readlines()          # 10GB のファイルなら 10GB 以上の机が必要
for line in lines:
    ...

# ✅ 1 行ずつ読む（机に置くのは常に 1 行分だけ）
with open("huge.log", encoding="utf-8") as f:
    for line in f:
        ...
```

| 書き方 | メモリ | 向いている場面 |
|---|---|---|
| `f.read()` / `f.readlines()` | ファイル全体分 | 小さい設定ファイルなど |
| `for line in f:` | 1 行分 | ログ・CSV など大きくなりうるファイル |
| `pandas.read_csv(..., chunksize=10000)` | 1 万行分ずつ | 大きな CSV をまとめて処理するとき |

JavaScript（Node.js）でも同じで、`fs.readFileSync` は全部読み込み、`fs.createReadStream` は少しずつ読みます。

```quiz
? 電源を切ると中身が消えるのはどれ？
- SSD
+ メモリ（RAM）
- HDD
> メモリは作業机です。速い代わりに、電源が切れると内容が消えます。残したいものはストレージに保存します。

? プログラムが遅いとき、まず疑うべきことは？
- CPU の足し算が遅い
+ ファイルやネットワークへのアクセスを何度もしている
- 変数の名前が長い
> 計算に比べて、ストレージやネットワークへのアクセスは何万倍も遅いです。回数を減らすのが一番効きます。

? 10GB のログファイルを処理するコードとして安全なのは？
- `lines = f.readlines()` で全部読んでから処理する
- `text = f.read()` で 1 つの文字列にする
+ `for line in f:` で 1 行ずつ処理する
> 1 行ずつなら、メモリに置くのは常に 1 行分だけで済みます。
```
