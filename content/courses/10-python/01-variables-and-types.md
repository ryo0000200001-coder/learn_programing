## このレッスンのゴール

- `=` が「等しい」ではなく **代入** だと説明できる
- 4 つの基本の型（int / float / str / bool）を見分けられる

## 変数＝名前のついた箱

```python
age = 20
name = "Ryo"
age = age + 1   # 右側を計算してから、左の箱に入れ直す → 21
```

`=` は数学の「等しい」ではなく、**右の値を左の名前に入れる** という意味です。
だから `age = age + 1` という、数学ではありえない式が成り立ちます。

## 基本の型

| 型 | 例 | 意味 |
|---|---|---|
| `int` | `20`, `-3` | 整数 |
| `float` | `3.14`, `1.0` | 小数 |
| `str` | `"hello"`, `'あ'` | 文字列（`"` か `'` で囲む） |
| `bool` | `True`, `False` | 真偽値（はい / いいえ） |
| `None` | `None` | 「何もない」を表す特別な値 |

```python
print(type(3.14))   # <class 'float'>
print("1" + "2")    # "12"  ← 文字列どうしは連結
print(1 + 2)        # 3
```

**同じ見た目でも型が違えば動きが違う** のがポイントです。

## 型の変換

```python
int("42")      # 42（文字列 → 整数）
str(42)        # "42"
float("1.5")   # 1.5
```

`input()` で受け取った値はいつも文字列なので、計算するときは `int(...)` で変換します。AI のコードでもよく見る形です。

## 演算子

| 記号 | 意味 | 例 |
|---|---|---|
| `+ - * /` | 四則演算（`/` は常に小数になる） | `7 / 2` → `3.5` |
| `//` | 割り算の整数部分 | `7 // 2` → `3` |
| `%` | 割り算の余り | `7 % 2` → `1` |
| `**` | べき乗 | `2 ** 3` → `8` |
| `== !=` | 等しい / 等しくない | `a == 1` |
| `< > <= >=` | 大小比較 | |
| `and or not` | かつ / または / ではない | |

## AI のコードではこう出てくる

```python
MAX_RETRIES = 3          # 全部大文字 = 「変えない値（定数）」という慣習
user_count: int = 0      # 「: int」は型ヒント（Lv4 で学びます）
is_valid = False         # is_ で始まる名前は bool のことが多い
```
