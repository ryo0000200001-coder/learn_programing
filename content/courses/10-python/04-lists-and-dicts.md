## このレッスンのゴール

- リスト（順番で管理）と辞書（名前で管理）を使い分けて説明できる
- JSON や API のデータが「辞書とリストの組み合わせ」だと分かる

## リスト：順番に並んだデータ

```python
scores = [80, 65, 92]
scores[0]        # 80（番号＝インデックスは 0 から）
scores[-1]       # 92（マイナスは後ろから）
scores.append(70)  # 末尾に追加 → [80, 65, 92, 70]
len(scores)      # 4（要素の数）
scores[1:3]      # [65, 92]（スライス：1 番目から 3 番目の手前まで）
```

## 辞書：名前（キー）でデータを取り出す

```python
user = {"name": "Ryo", "age": 20}
user["name"]           # "Ryo"
user["email"] = "a@b"  # 追加
user.get("tel")        # None（無くてもエラーにならない）
user["tel"]            # KeyError！（無いキー）
```

AI のコードで `.get("key", 既定値)` が多いのは、**キーが無い場合でも止まらないようにするため** です。

## 辞書をループする

```python
for key, value in user.items():
    print(key, value)
```

## 組み合わせ ＝ 現実のデータの形

```python
users = [
    {"name": "Ryo", "skills": ["Python", "SQL"]},
    {"name": "Ken", "skills": ["Go"]},
]
users[0]["skills"][1]   # "SQL"
```

Web API から返ってくる JSON は、ほぼこの形です。
**外側から 1 段ずつ「リストなら番号、辞書ならキー」** と読んでいけば、どんなに深くても読めます。

## 注意：コピーではなく「同じものを指す」

```python
a = [1, 2]
b = a
b.append(3)
print(a)   # [1, 2, 3] ← a も変わる！
```

`b = a` は箱の中身をコピーするのではなく、**同じリストに 2 つ目の名札をつける** だけです。
別物にしたいときは `b = a.copy()`。AI のコードにバグが潜みやすいポイントです。

## その他のコレクション

| 名前 | 書き方 | 特徴 |
|---|---|---|
| タプル | `(1, 2)` | 変更できないリスト |
| セット | `{1, 2}` | 重複なし・順番なし |

## 他の言語では

| Python | JavaScript | 多くの言語での呼び名 |
|---|---|---|
| リスト `[1, 2]` | 配列 `[1, 2]` | 配列 / Array / Vec |
| 辞書 `{"a": 1}` | オブジェクト `{a: 1}` / Map | マップ / ハッシュ / Dictionary |

```quiz
? `colors = ["赤", "青", "緑"]` のとき `colors[1]` は？
- "赤"
+ "青"
- "緑"
> インデックスは 0 から数えます。

? 辞書に無いキーを `d["x"]` で取り出すと？
- None が返る
+ KeyError になる
- 空文字が返る
> エラーにしたくないときは d.get("x") を使います。

? `data["items"][0]["price"]` はどう読む？
+ data の "items"（リスト）の 0 番目（辞書）の "price"
- data の 0 番目の "items" の "price"
> 左から 1 段ずつ、辞書ならキー・リストなら番号で取り出します。
```
