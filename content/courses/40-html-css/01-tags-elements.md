## このレッスンのゴール

- HTML の基本の形（`<!doctype html>`・`head`・`body`）を読める
- タグ・要素・属性という言葉を使い分けられる
- よく使うタグが何を表すか分かり、`div` だらけのコードとの違いが説明できる

## HTML は「意味の札」を付ける言語

HTML は、文章のあちこちに **タグ** という札を付けて、「ここは見出し」「ここは段落」「ここはリンク」と **意味（役割）** を伝える言語です。プログラミング言語のように計算はしません。

```html
<h1>買い物メモ</h1>
<p>今日買うものです。</p>
```

| 用語 | 例 | 意味 |
|---|---|---|
| **開始タグ** | `<p>` | ここから |
| **終了タグ** | `</p>` | ここまで（`/` が付く） |
| **要素** | `<p>今日買うものです。</p>` | 開始タグから終了タグまでのひとまとまり |
| **中身** | `今日買うものです。` | 要素の中の文字や、別の要素 |

Python で言うと、HTML は **入れ子になった辞書やリスト** のようなものです。「ページ」の中に「本文」があり、その中に「見出し」と「段落」がある、という **木の形** になっています。JavaScript コースの「DOM とイベント」で、ブラウザがこの木を DOM として扱うことを学びました。

## ページの基本の形

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>買い物メモ</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>買い物メモ</h1>
    <p>今日買うものです。</p>
    <script src="app.js"></script>
  </body>
</html>
```

| 部分 | 意味 |
|---|---|
| `<!doctype html>` | 「今の HTML の書き方です」という宣言。いつも 1 行目 |
| `<html lang="ja">` | 全体を包む。`lang="ja"` は日本語のページという意味（読み上げや翻訳に使われる） |
| `<head>` | **画面に出ない情報**：文字コード・タイトル・CSS の読み込み |
| `<meta charset="utf-8">` | 文字コードは UTF-8（コンピュータの基礎コースの「文字コード」） |
| `<meta name="viewport" ...>` | スマホで正しい幅で表示する（レッスン 6） |
| `<title>` | ブラウザのタブに出る名前 |
| `<link rel="stylesheet">` | CSS のファイルを読み込む |
| `<body>` | **画面に出る中身** |
| `<script src="...">` | JavaScript を読み込む。`body` の最後に置くと、HTML を全部読んでから動く |

このサイトの `site/index.html` も、ほぼこの形です。開いて見比べてみましょう。

## よく使うタグ

### 文章の構造

| タグ | 意味 |
|---|---|
| `<h1>`〜`<h6>` | 見出し。`h1` がいちばん大きい（ページに 1 つが目安） |
| `<p>` | 段落 |
| `<ul>` / `<ol>` + `<li>` | 箇条書き（`ul` は点、`ol` は番号） |
| `<a href="URL">` | リンク |
| `<img src="画像" alt="説明">` | 画像（終了タグが無い） |
| `<strong>` / `<em>` | 強調 |
| `<br>` | 改行（終了タグが無い） |
| `<table>` `<tr>` `<th>` `<td>` | 表（行・見出しのマス・普通のマス） |

```html
<ul>
  <li>りんご</li>
  <li>牛乳</li>
</ul>
```

`<img>` や `<br>`、`<meta>` のように、**中身を持たないタグ** は終了タグを書きません（`<br />` と書くこともあります）。

### 意味のある入れ物（セマンティックタグ）

| タグ | 意味 |
|---|---|
| `<header>` | ページや区切りの頭（ロゴ・メニュー） |
| `<nav>` | メニュー（ナビゲーション） |
| `<main>` | ページの主な中身（1 つだけ） |
| `<section>` / `<article>` | 内容のまとまり／それだけで完結する記事 |
| `<footer>` | ページや区切りの終わり（著作権表示など） |
| `<div>` | **意味の無い** 入れ物。見た目を整えるためだけに使う |
| `<span>` | 文の途中の、意味の無い入れ物 |

```html
<!-- ⚠️ 全部 div -->
<div class="header"><div class="nav">...</div></div>
<div class="main">...</div>

<!-- ✅ 意味のあるタグ -->
<header><nav>...</nav></header>
<main>...</main>
```

見た目は同じにできますが、意味のあるタグを使うと、**画面の読み上げソフト**（目の不自由な人が使う）や **検索エンジン** が、ページの作りを正しく理解できます。

## 属性：タグに付ける追加の情報

```html
<a href="https://example.com" target="_blank" rel="noopener">サイトへ</a>
<img src="cat.jpg" alt="窓辺で寝ている猫" width="300">
<p id="intro" class="note important">はじめに</p>
```

`名前="値"` の形で、開始タグの中に書きます。Python の関数のキーワード引数（`f(href="...")`）に似ています。

| 属性 | 意味 |
|---|---|
| `href` | リンク先 |
| `target="_blank"` | 新しいタブで開く |
| `src` | 画像やスクリプトのファイルの場所 |
| `alt` | 画像の説明。画像が出ないときや読み上げに使われる |
| `id` | ページの中で 1 つだけの名前（レッスン 3） |
| `class` | グループの名前。スペース区切りで複数付けられる（レッスン 3） |
| `data-...` | 自由に付けてよい属性。JavaScript から読む（このサイトのクイズの `data-quiz` など） |

## コメントと空白

```html
<!-- これはコメント。画面には出ない -->
<p>改行や
   スペースを   たくさん入れても</p>
```

HTML では、**改行や連続したスペースは 1 つの空白** として表示されます。改行したいときは段落を分けるか `<br>` を使います。

⚠️ コメントは画面に出ませんが、**「ページのソースを表示」で誰でも見られます**。メモのつもりで秘密を書かないようにしましょう。

## AI のコードではこう出てくる

| 見かけたら | チェック |
|---|---|
| `<html>` に `lang` が無い／`<meta charset>` が無い | ⚠️ 読み上げや文字化けで困ることがある |
| `<img src="...">` に `alt` が無い | ⚠️ 画像の説明が無い。飾りだけの画像なら `alt=""` |
| 全部 `<div>` で、クリックできる場所も `<div onclick=...>` | ⚠️ キーボードで操作できない。ボタンは `<button>`（レッスン 2） |
| `<h1>` の次がいきなり `<h4>` | 見出しは順番に（大きさは CSS で変える） |
| `target="_blank"` | 今のブラウザでは `rel="noopener"` 相当が自動で付くが、古いコードでは付けておくのが定番 |

```quiz
? `<p class="note">今日買うもの</p>` のうち、「属性」はどれ？
- `<p>`
+ `class="note"`
- `今日買うもの`
> 属性は開始タグの中に `名前="値"` で書く追加の情報です。`<p>...</p>` 全体が要素、`今日買うもの` は中身です。

? `<head>` の中に書くものとして正しいのは？
+ 文字コードの指定やタイトル、CSS の読み込みなど、画面に直接出ない情報
- ページの本文
- 画像やボタン
> 画面に出る中身は `<body>` に、ページについての情報は `<head>` に書きます。

? `<div class="nav">` の代わりに `<nav>` を使う利点は？
- 表示が速くなる
- CSS が不要になる
+ 読み上げソフトや検索エンジンに「ここはメニュー」という意味が伝わる
> 見た目は同じにできますが、意味のあるタグはページの作りを機械に伝えられます。
```
