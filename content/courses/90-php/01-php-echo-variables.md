## このレッスンのゴール

- `<?php`・`echo`・`$変数` を読める
- 文字列のつなぎ方（`.`）と、`"..."` と `'...'` の違いが分かる
- `==` と `===` の違いを説明し、AI のコードで `==` を見たら確認できる

## PHP とは

**PHP** は、Web サーバーの上で動いて HTML を作る言語です。世界中の Web サイトのかなりの割合で使われていて、特に **WordPress**（ブログ・会社のサイト）や **Laravel**（Web アプリのフレームワーク）で出会います。「既存のサイトを少し直してほしい」と頼まれたときに、読めると役立つ言語です。

## ファイルの形と echo

```php
<?php
$name = "Ryo";
$price = 120;
$count = 3;
echo "こんにちは、$name さん\n";
echo 'こんにちは、$name さん' . "\n";
echo "合計 " . ($price * $count) . " 円\n";
echo "合計 {$price} 円 × {$count}\n";
```

```text
こんにちは、Ryo さん
こんにちは、$name さん
合計 360 円
合計 120 円 × 3
```

（このコースの出力は、すべて PHP 8.3 で実際に実行したものです）

| PHP | 意味 | Python で言うと |
|---|---|---|
| `<?php` | ここから PHP のコード（ファイルの先頭に書く） | — |
| `$name = "Ryo";` | 変数。**名前の前に必ず `$`**、文の終わりに `;` | `name = "Ryo"` |
| `echo ...;` | 出力する（Web なら HTML に書き出される） | `print(...)` |
| `"...$name..."` | ダブルクォートの中では **変数が置き換わる** | `f"...{name}..."` |
| `'...$name...'` | シングルクォートでは **そのまま** | `"...$name..."` |
| `"..." . "..."` | **`.` で文字列をつなぐ**（`+` ではない） | `"..." + "..."` |
| `{$price}` | 変数の範囲をはっきりさせる | `{price}` |

`"` と `'` の違いは、シェルコースのレッスン 2 とまったく同じです。PHP はシェルや Perl の影響を受けているので、`$` の変数もそこから来ています。

⚠️ JavaScript や Python の癖で `"合計 " + $total` と書くと、PHP は **数の足し算** をしようとします（`"合計 "` は数にならないので、PHP 8 ではエラー）。つなぐのは `.` です。

### HTML の中に埋め込む

PHP は、もともと **HTML の中に少しだけプログラムを埋め込む** ために作られました。

```php
<p>こんにちは、<?= htmlspecialchars($name) ?> さん</p>
```

`<?= ... ?>` は `<?php echo ... ?>` の短い書き方です。`htmlspecialchars` は XSS を防ぐためのエスケープ（レッスン 4・セキュリティのコースのレッスン 4）です。

## 型を見る：var_dump

```php
var_dump($price, "120", 1.5, true, null);
```

```text
int(120)
string(3) "120"
float(1.5)
bool(true)
NULL
```

`var_dump` は、**型と値を両方** 表示します（Python の `repr()` と `type()` を合わせたもの）。`string(3)` の 3 は **バイト数** です。

```php
var_dump(strlen("りんご"), mb_strlen("りんご"));
// int(9)  int(3)
```

`strlen` はバイト数、`mb_strlen` は文字数です（コンピュータの基礎コースの「文字コード」）。日本語を扱うときは `mb_` で始まる関数を使います。

## ⚠️ == はゆるい、=== は厳しい

PHP の比較でいちばん大事なところです。

```php
var_dump("120" == 120);     // bool(true)   ← 文字列と数なのに等しい
var_dump("120" === 120);    // bool(false)
var_dump("1e3" == "1000");  // bool(true)   ← "1e3" を 1000 という数だと解釈した
var_dump(null == false);    // bool(true)
var_dump("0" == false);     // bool(true)
var_dump("abc" == 0);       // bool(false)  （PHP 7 までは true だった）
var_dump(0 == "");          // bool(false)  （PHP 7 までは true だった）
```

| 演算子 | 意味 |
|---|---|
| `==` | **型をそろえてから** 比べる（ゆるい比較）。文字列が数っぽければ数として比べる |
| `===` | **型も値も同じ** なら真（厳しい比較） |
| `!=` / `!==` | その否定 |

`"1e3" == "1000"` が真になるのは、どちらも「数として読める文字列」なので、数（1000）に変換してから比べたからです。パスワードのハッシュやトークンを `==` で比べると、まったく違う値が等しくなってしまう、という有名な脆弱性もありました。

```php
var_dump(md5("240610708") == md5("QNKCDZO"));    // bool(true)   ← 違う文字列なのに
var_dump(md5("240610708") === md5("QNKCDZO"));   // bool(false)
```

2 つの MD5 の値は、どちらも `0e` の後に数字だけが続く文字列になり、PHP が「0 × 10 の何乗 ＝ 0」という数だと解釈して、0 == 0 で真にしてしまいます（実際に実行した結果です）。

**PHP では、基本的に `===` を使う** のが安全です。JavaScript の `==` と `===`（JavaScript コースのレッスン 1）と同じ考え方です。

### 数っぽい文字列

```php
$x = "5 apples";
var_dump((int)$x);           // int(5)
var_dump(intdiv(7, 2), 7 / 2, 7 % 2);   // int(3) float(3.5) int(1)
```

`(int)` で数に変換すると、先頭の数の部分だけが使われます。`7 / 2` は Python 3 と同じく **3.5**（小数）で、整数の割り算は `intdiv` です。

## 未定義の変数と ??

```php
echo $nope;
echo "\n続きます\n";
```

```text
PHP Warning:  Undefined variable $nope in .../p1.php on line 16

続きます
```

存在しない変数を使うと、**警告を出して、空として先に進みます**（シェルの空の変数と同じ。Python なら `NameError` で止まる）。

```php
var_dump($undefined ?? "default");   // string(7) "default"
```

`??` は「**左が無い（null）なら右**」です。Python の `x if x is not None else "default"`、JavaScript の `??` と同じです。フォームの値（`$_POST['name'] ?? ''`）でよく使います（レッスン 4）。

## AI のコードではこう出てくる

| 見かけたら | チェック |
|---|---|
| `if ($a == $b)` | ⚠️ ゆるい比較。型の違うものが等しくなりうる。`===` に |
| `"..." + $x` で文字列をつなごうとしている | ⚠️ PHP は `.` でつなぐ |
| `strlen($name) > 20` で文字数の制限 | ⚠️ バイト数。日本語は `mb_strlen` |
| `$_GET['id'] ?? null` | ✅ 無ければ null |
| `@$undefined` | `@` は警告を **消す**。問題を隠しているので要注意 |
| `declare(strict_types=1);` | 関数の引数の型を厳しくチェックする設定（レッスン 2） |
