## このレッスンのゴール

- URL を部品に分けて読める
- DNS・IP アドレス・ポートの役割を説明できる
- `localhost:8000` の意味が分かる

## URL を分解する

```text
https://api.example.com:443/users/42?sort=new#profile
└─┬─┘   └──────┬──────┘└┬┘└───┬───┘└───┬───┘└──┬──┘
スキーム     ホスト名   ポート  パス    クエリ   フラグメント
```

| 部品 | 意味 | 例 |
|---|---|---|
| スキーム | 通信の方法 | `https`（暗号化あり）、`http`（なし） |
| ホスト名（ドメイン） | どのサーバーか | `api.example.com` |
| ポート | そのサーバーのどの窓口か | `443`（https の既定値なので普段は省略） |
| パス | サーバーの中のどの資源か | `/users/42`（id 42 のユーザー） |
| クエリ | 追加の条件 | `?sort=new`（新しい順で） |
| フラグメント | ページ内の位置。**サーバーには送られない** | `#profile` |

fashion_news の解説で、URL から `utm_source` などを取り除いていたのは、この **クエリ** の部分です。

## DNS：名前から住所を引く電話帳

コンピュータ同士は、`93.184.215.14` のような **IP アドレス**（インターネット上の住所）で相手を探します。
人間には覚えにくいので、`example.com` のような名前を付け、**DNS**（ドメインネームシステム）という仕組みで名前 → IP アドレスに変換します。

```text
ブラウザ「api.example.com の住所は？」
   ↓
DNS サーバー「93.184.215.14 です」
   ↓
ブラウザ → 93.184.215.14 に接続
```

新しいサイトを公開したのにしばらくつながらない、というときは、この DNS の情報が世界中に行き渡るのを待っていることがあります。

## ポート：建物の部屋番号

IP アドレスが「建物の住所」なら、**ポート** は「部屋番号」です。1 台のサーバーで、いくつものプログラムが別々のポートで待ち受けられます。

| ポート | よく使うもの |
|---|---|
| 80 | http |
| 443 | https |
| 22 | SSH（サーバーへのリモートログイン） |
| 5432 | PostgreSQL（データベース） |
| 3000 / 5173 / 8000 | 開発中の Web サーバー（Node.js・Vite・Python などの慣習） |

## localhost：自分自身

```text
http://localhost:8000
http://127.0.0.1:8000
```

`localhost`（IP アドレスでは `127.0.0.1`）は **「このパソコン自身」** を指す特別な名前です。
AI が「サーバーを起動したので http://localhost:8000 を開いてください」と言うのは、「あなたのパソコンの 8000 番の部屋で、いまサーバーが待ち受けています」という意味です。他のパソコンからは見えません。

## HTTPS：暗号化された通信

`https` の `s` は Secure。途中の経路（Wi-Fi など）で中身を盗み見られたり、書き換えられたりしないよう暗号化します。
**パスワードや個人情報を扱うなら https は必須** で、今は普通のサイトでもほぼすべて https です。

## 全体の流れ

```text
① URL を入力 → ② DNS でホスト名を IP アドレスに変換
→ ③ その IP アドレスのポート 443 に接続し、暗号化の準備（TLS）
→ ④ HTTP リクエストを送る（次のレッスン）
→ ⑤ サーバーのプログラムが処理して HTTP レスポンスを返す
→ ⑥ ブラウザが表示する
```

```quiz
? `https://shop.example.com/items/7?color=red#reviews` のうち、サーバーに送られないのは？
- /items/7
- color=red
+ #reviews
> フラグメント（# 以降）はブラウザの中だけで使われます。

? DNS の役割は？
+ ドメイン名を IP アドレスに変換する
- 通信を暗号化する
- データを保存する
> インターネットの電話帳のような仕組みです。

? 友達のパソコンから `http://localhost:8000` を開くと？
- あなたのパソコンのサーバーが見える
+ 友達のパソコン自身の 8000 番ポートにつながる
> localhost は「そのパソコン自身」を指します。
```
