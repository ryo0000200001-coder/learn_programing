## このレッスンのゴール

- 終了コード（0 が成功）と `$?` の意味を説明できる
- `if [ -f "$file" ]` などの条件を読める
- `&&`・`||`・`case` を使った分岐を読める

## 終了コード：コマンドの「結果の番号」

どのコマンドも、終わるときに **終了コード**（0〜255 の数）を返します。

| 終了コード | 意味 |
|---|---|
| **0** | **成功** |
| 0 以外（1、2、127 …） | 失敗（番号の意味はコマンドごと。127 は「コマンドが見つからない」） |

```bash
ls notes.txt > /dev/null
echo $?        # 0   ← 直前のコマンドの終了コード

ls nope 2> /dev/null
echo $?        # 2
```

`$?` は「直前のコマンドの終了コード」です。⚠️ Python の `True`（1）/`False`（0）と **逆** で、**0 が成功** なのに注意してください。

Python のプログラムでは、`sys.exit(1)` で終了コードを返せます。例外で止まったときは 1 になります。CI（公開とクラウドのコースのレッスン 7）が ✅ / ❌ を判断しているのも、この終了コードです（`pytest` がテストの失敗で 0 以外を返す）。

## if：コマンドが成功したら

```bash
if grep -q "b" notes.txt; then
  echo "見つかった"
else
  echo "無い"
fi
```

シェルの `if` は、**後ろのコマンドを実行して、終了コードが 0 なら then の方** に進みます。`grep -q` は「見つかったら 0、見つからなければ 1」を返すだけのコマンドです。

| 部分 | 意味 |
|---|---|
| `if コマンド; then` | コマンドが成功したら |
| `elif コマンド; then` | Python の `elif` |
| `else` | それ以外 |
| `fi` | if の終わり（if を逆から書いたもの） |

インデントは見やすさのためだけで、Python と違って意味はありません。

## [ ]：条件を調べるコマンド

```bash
if [ -f "$file" ]; then
```

`[` は、実は **条件を調べて終了コードを返すコマンド** です（`test` という名前でもある）。だから `[` の後ろと `]` の前には **スペースが必要** です（`[-f "$file"]` はエラー）。

### ファイルを調べる

| 書き方 | 真になるとき |
|---|---|
| `[ -f "$p" ]` | ファイルがある |
| `[ -d "$p" ]` | ディレクトリがある |
| `[ -e "$p" ]` | 何かがある（ファイルでもディレクトリでも） |
| `[ -x "$p" ]` | 実行できる |
| `[ ! -f "$p" ]` | ファイルが **無い**（`!` は否定） |

### 文字と数を比べる

| 文字列 | 数 | 意味 |
|---|---|---|
| `[ "$a" = "$b" ]` | `[ "$a" -eq "$b" ]` | 等しい |
| `[ "$a" != "$b" ]` | `[ "$a" -ne "$b" ]` | 等しくない |
| `[ -z "$a" ]` | | 空 |
| `[ -n "$a" ]` | | 空でない |
| | `-lt` `-le` `-gt` `-ge` | `<` `<=` `>` `>=` |

**数は `-gt` などの記号の英語**（greater than）で比べます。`<` `>` を使うと、**文字として** 比べることになります。

```bash
[ 3 -gt 10 ] && echo yes || echo no       # no（数として 3 > 10 は偽）
[ "10" \> "9" ] && echo "10 > 9" || echo "10 < 9"   # 10 < 9（文字として "1" < "9"）
(( 10 > 9 )) && echo "数: 10 > 9"          # 数: 10 > 9（(( )) の中は数の比較）
```

### 引用符を忘れると

```bash
x=""
[ $x = "y" ]
# bash: [: =: unary operator expected
```

x が空なので、`[ = "y" ]` として実行され、「`=` の左に何も無い」というエラーになりました。`[ "$x" = "y" ]` と書けば、`[ "" = "y" ]` になって正しく偽（終了コード 1）になります。**レッスン 2 の「変数は引用符で囲む」は、ここでも大事** です。

### [[ ]]：bash の便利版

```bash
[[ "abc" == a* ]] && echo match     # match（パターンで比べられる）
```

`[[ ... ]]` は bash の書き方で、`&&`・`||` をそのまま中に書けたり、パターン（`a*`）や正規表現（`=~`）で比べられたりします。引用符の付け忘れにも強いです。ただし `#!/bin/sh` では使えないことがあります（レッスン 1）。

## 実際のスクリプト

```bash
#!/usr/bin/env bash
file="$1"                                   # 1 つ目の引数（レッスン 4）
if [ -z "$file" ]; then
  echo "使い方: $0 ファイル名" >&2          # >&2 はエラーの出力へ（レッスン 5）
  exit 1
fi
if [ -f "$file" ]; then
  echo "$file はファイルです（$(wc -l < "$file") 行）"
elif [ -d "$file" ]; then
  echo "$file はディレクトリです"
else
  echo "$file は見つかりません" >&2
  exit 2
fi
```

```text
$ ./check.sh
使い方: ./check.sh ファイル名            （終了コード 1）
$ ./check.sh notes.txt
notes.txt はファイルです（3 行）        （終了コード 0）
$ ./check.sh .
. はディレクトリです
$ ./check.sh nothing
nothing は見つかりません                （終了コード 2）
```

`exit 番号` で、スクリプト自身の終了コードを決めています。こうしておくと、このスクリプトを他のスクリプトや CI から使ったときに、成功・失敗が伝わります。

## && と ||：短い分岐

```bash
grep -q b notes.txt && echo found || echo missing     # found
mkdir -p build && cd build                            # mkdir が成功したら cd
command -v jq || echo "jq がありません"                # jq が無ければ表示
```

| 書き方 | 意味 |
|---|---|
| `A && B` | A が **成功したら** B |
| `A \|\| B` | A が **失敗したら** B |
| `A && B \|\| C` | A が成功したら B、失敗したら C（⚠️ B が失敗しても C が動く。厳密には if と違う） |

## case：値で分ける

```bash
case "$1" in
  start) echo "開始します" ;;
  stop)  echo "停止します" ;;
  *)     echo "start か stop を指定してください" ;;
esac
```

Python の `match` 文に当たります。`*)` はどれにも当たらなかったとき（Python の `case _:`）、`;;` は 1 つの場合の終わり、`esac` は case を逆から書いたものです。`start|begin)` のように `|` で複数書けます。

## AI のコードではこう出てくる

| 見かけたら | 読み方・チェック |
|---|---|
| `if [ $# -lt 1 ]; then echo "usage: ..."; exit 1; fi` | 引数が 1 つも無ければ使い方を出して終わる（定番の書き出し） |
| `if ! command -v docker >/dev/null; then` | docker が入っていなければ |
| `[ $x = "y" ]` | ⚠️ 引用符が無い。x が空だとエラー |
| `[ "$a" > "$b" ]` | ⚠️ `>` はリダイレクト（レッスン 5）になり、`$b` という名前のファイルができてしまう。数なら `-gt` |
| `cd dir \|\| exit 1` | cd に失敗したら止まる（レッスン 6） |
| `exit 0` が最後にある | 成功で終わる（途中の失敗を隠していないか注意） |

```quiz
? シェルで「成功」を表す終了コードは？
+ 0
- 1
- -1
> 0 が成功、0 以外が失敗です。Python の True(1)/False(0) と逆なので注意します。

? `[ 3 -gt 10 ]` と `[ "3" \> "10" ]` の結果は？
- どちらも偽
- どちらも真
+ 前は偽（数として比べる）、後は真（文字として "3" > "1" と比べる）
> `-gt` は数の比較、`>` は文字の比較です。数を比べるときは `-gt` などか、`(( ))` を使います。

? `mkdir -p build && cd build` の意味は？
- mkdir と cd を同時に実行する
+ mkdir が成功したときだけ cd する
- mkdir が失敗したときだけ cd する
> `&&` は「左が成功したら右」です。失敗したら右は実行されません。
```
