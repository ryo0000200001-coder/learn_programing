## このレッスンのゴール

- シェルスクリプトが何で、Python のスクリプトとどこが似ているか説明できる
- 1 行目の `#!/usr/bin/env bash` の意味が分かる
- `Permission denied` が出たときに、何をすればよいか分かる

ターミナルと Git のコースで、コマンドを 1 つずつ打つ方法を学びました。このコースでは、**コマンドを並べたファイル（シェルスクリプト）** を読めるようになることを目指します。

## シェルとシェルスクリプト

**シェル** は、ターミナルに打った命令を読んで実行するプログラムです。いちばんよく使われるのが **Bash**（バッシュ）で、Linux の標準、Windows の Git Bash の中身もこれです（Mac の標準は zsh ですが、書き方はほとんど同じです）。

**シェルスクリプト** は、そのコマンドを **上から順に並べたテキストファイル** です。拡張子は `.sh` にすることが多いです。

```bash
#!/usr/bin/env bash
# あいさつするスクリプト
name="Ryo"
echo "こんにちは、$name さん"
echo "今日は $(date +%Y-%m-%d) です"
echo "1 + 2 = $((1 + 2))"
```

```text
こんにちは、Ryo さん
今日は 2026-11-23 です
1 + 2 = 3
```

（このコースの出力は、すべて実際に bash 5.2 で実行したものです）

Python で書くと、こうなります。

```python
from datetime import date
name = "Ryo"
print(f"こんにちは、{name} さん")
print(f"今日は {date.today()} です")
print(f"1 + 2 = {1 + 2}")
```

| シェル | Python | 意味 |
|---|---|---|
| `name="Ryo"` | `name = "Ryo"` | 変数に入れる（レッスン 2） |
| `echo "...$name..."` | `print(f"...{name}...")` | 表示する |
| `$(date +%Y-%m-%d)` | `date.today()` | **コマンドを実行して、その出力を文字として使う** |
| `$((1 + 2))` | `1 + 2` | 計算 |
| `# ...` | `# ...` | コメント |

シェルは **「コマンドを動かすこと」が得意** で、計算や複雑なデータの処理は苦手です。ファイルのコピー・ツールの起動・インストール手順のような、**コマンドを順番に実行する作業** を自動化するのに使います。

## 1 行目の `#!`（シバン）

```bash
#!/usr/bin/env bash
```

`#!` で始まる 1 行目を **シバン**（shebang）と呼びます。「このファイルは **bash で実行してね**」という指定です。

| 書き方 | 意味 |
|---|---|
| `#!/usr/bin/env bash` | PATH から bash を探して使う（**おすすめ**。どこに bash が入っていても動く） |
| `#!/bin/bash` | `/bin/bash` を使う（多くの Linux ではこれでも OK） |
| `#!/bin/sh` | bash ではなく、もっと機能の少ない **sh** で動く。bash の書き方（`[[ ]]` など）が使えないことがある |
| `#!/usr/bin/env python3` | Python のスクリプトにも同じ仕組みが使える |

## 実行する

```text
$ ./hello.sh
bash: ./hello.sh: Permission denied
```

作ったばかりのファイルには、**実行してよいという権限** が付いていません。`chmod +x` で付けます。

```bash
chmod +x hello.sh   # 実行の権限（x）を付ける
./hello.sh          # 実行できるようになった
```

| 実行の仕方 | 意味 |
|---|---|
| `./hello.sh` | 権限を付けたファイルを直接実行。シバンのシェルで動く |
| `bash hello.sh` | bash に「このファイルを読んで」と頼む。**権限が無くても動く** |
| `hello.sh`（`./` 無し） | `command not found`。ターミナルは PATH の中しか探さない（ターミナルと Git のコースのレッスン 2）ので、「ここにあるファイル」と `./` で伝える |
| `source hello.sh` / `. hello.sh` | **今のシェルの中で** 実行する。スクリプトで作った変数が、終わった後も残る（`.venv/bin/activate` などがこれ） |

`ls -l` で `-rwxr-xr-x` のように `x` が見えたら、実行の権限が付いています。

### Windows では

Git Bash なら、`.sh` のファイルをそのまま `bash hello.sh` で動かせます。PowerShell は別のシェルなので、`.sh` は動きません（PowerShell 用のスクリプトは `.ps1`）。
⚠️ Windows で作ったスクリプトを Linux で動かすと `$'\r': command not found` が出ることがあります。改行コードが CRLF になっているためです（コンピュータの基礎コースのレッスン 3）。

## AI のコードではこう出てくる

```bash
#!/usr/bin/env bash
set -euo pipefail          # レッスン 6：失敗したら止まる、の設定

echo "依存ライブラリをインストールします..."
pip install -r requirements.txt
echo "完了しました"
```

| 見かけたら | 読み方 |
|---|---|
| `#!/usr/bin/env bash` | bash 用のスクリプト |
| `#!/bin/sh` ＋ `[[ ... ]]` | ⚠️ sh では動かないことがある書き方。シバンを bash に |
| `chmod +x scripts/*.sh` | scripts の中の .sh 全部に実行の権限を付ける |
| `source .env` / `. ./venv/bin/activate` | 今のシェルに変数や設定を読み込む |
| `bash <(curl -s https://...)` / `curl ... \| bash` | ⚠️ ネットのスクリプトを中身を見ずに実行（ターミナルと Git のコースのレッスン 2） |

```quiz
? `./deploy.sh` を実行したら `Permission denied` と出た。まずすることは？
- パソコンを再起動する

- ファイルの拡張子を .py に変える
> 作ったばかりのファイルには実行の権限がありません。`chmod +x` で付けるか、bash に読ませて実行します。

? スクリプトの 1 行目の `#!/usr/bin/env bash` の意味は？
- コメントなので何の意味も無い
+ このファイルを bash で実行する、という指定
- bash をインストールする命令
> `#!` で始まる 1 行目（シバン）は、ファイルを直接実行したときに使うプログラムを指定します。

? `echo "今日は $(date +%Y-%m-%d) です"` の `$(...)` は何をしている？
- `$` という文字を表示している

- 計算をしている

```
