## このレッスンのゴール

- 初めて見るコードを、決まった手順で読み始められる
- 分からない部分を「調べるべきもの」と「気にしなくていいもの」に分けられる

## コツ 1：全体をざっと眺める（細部は読まない）

最初から 1 行ずつ理解しようとすると疲れてしまいます。まずはスクロールして

- 何行くらいあるか
- `def`（関数）や `class` がいくつあるか
- 一番下で何が実行されているか

だけを見ます。地図を広げて、全体の形をつかむイメージです。

## コツ 2：上の方の import を見る

```python
import requests
import csv
from datetime import date
```

`import` は「外から道具を借りてくる」宣言です。ここを見るだけで
「ネットに接続する（requests）」「CSV ファイルを扱う」「日付を使う」コードだと予想できます。

## コツ 3：実行の入口を探す

Python なら一番下の

```python
if __name__ == "__main__":
    main()
```

JavaScript なら、ボタンのクリックなどの **イベント** や、一番外側で呼ばれている関数が入口です。
入口から、呼ばれている関数を順にたどっていきます。

## コツ 4：名前から意味を推測する

AI のコードは名前がとても丁寧です。`fetch_weather(city)` なら「都市名を受け取って天気を取ってくる関数」と読めます。
**中身を読む前に、名前から予想 → 中身で答え合わせ** をすると、速く・深く読めます。

## コツ 5：分からないものを 3 種類に分ける

| 種類 | 例 | どうする？ |
|---|---|---|
| 言語の文法 | `lambda`, `=>`, `async` | このサイトのレッスンで学ぶ |
| ライブラリの機能 | `requests.get`, `pd.read_csv` | 名前から推測。必要なら公式ドキュメント |
| そのプログラム独自の名前 | `calc_score`, `user_list` | 定義されている場所を探して読む |

全部を一度に理解する必要はありません。**文法を少しずつ増やしていくのが、このサイトの目的** です。

```quiz
? 初めて見るコードを読むとき、最初にすることとして良いのは？
- 1 行目から完全に理解するまで先に進まない
+ 全体をざっと眺めて形をつかむ
- 分からない単語を全部調べる
> 細部は後回し。まず全体の形（関数の数・入口・import）をつかみます。

? import 文を見ると何が分かる？
+ そのコードが外部のどんな道具を使っているか
- そのコードの実行にかかる時間
- コードを書いた人の名前
> import は使う道具の一覧なので、コードの目的を推測するヒントになります。

? `requests.get(url)` の `get` が分からないとき、それはどの種類？
- 言語の文法
+ ライブラリの機能
- そのプログラム独自の名前
> requests というライブラリが持っている機能です。名前から「URL のデータを取ってくる」と推測できます。
```
