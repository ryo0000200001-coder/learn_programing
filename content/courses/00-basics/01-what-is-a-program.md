## このレッスンのゴール

- プログラムが **上から下へ、1 行ずつ** 実行されることを説明できる
- どんなプログラムも **入力 → 処理 → 出力** の形で整理できると分かる

## プログラム＝コンピュータへの指示書

プログラムは「料理のレシピ」に似ています。レシピは上から順に読み、書いてある通りに手を動かします。
コンピュータも同じで、書かれた指示を **上から順番に** 実行していきます。

```python
name = "Ryo"
print("こんにちは")
print(name)
```

1. `name` という名前の箱に `"Ryo"` を入れる
2. 「こんにちは」と表示する
3. 箱 `name` の中身（Ryo）を表示する

順番を入れ替えると結果も変わります。**「この行が実行される時点で、何が決まっているか」** を意識するのが、コードを読む第一歩です。

## 入力 → 処理 → 出力

どんなに大きなプログラムでも、分解するとこの 3 つになります。

| | 例：天気アプリ |
|---|---|
| **入力** | 地名、インターネットから取ってきたデータ |
| **処理** | 気温を℃に変換、明日の分だけ取り出す |
| **出力** | 画面に「明日は 18℃・晴れ」と表示 |

AI が書いた長いコードを渡されたら、まず **「入力はどこ？ 出力はどこ？」** を探しましょう。
真ん中の「処理」は、あとから少しずつ読めば大丈夫です。

## 「上から順番」の例外

実は、上から順番に流れない場面がいくつかあります。これから学ぶ内容です。

- **条件分岐（if）**：条件によって実行する行を選ぶ
- **繰り返し（for / while）**：同じ部分を何度も実行する
- **関数**：あとで呼ばれたときに実行される「予約」の部分

この 3 つさえ押さえれば、どの言語でもプログラムの流れを追えるようになります。

## 読んでみよう

```python
price = 1000
tax = price * 0.1
print(price + tax)
```

<details><summary>何が表示される？</summary>

`1100.0` が表示されます。`price * 0.1` で 100.0（小数）ができ、1000 と足して 1100.0 になります。
入力＝`price`、処理＝税の計算、出力＝`print` です。

</details>
